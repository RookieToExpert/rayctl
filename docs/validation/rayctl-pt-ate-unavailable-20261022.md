# PT ATE 服务不可用提示验收

日期：2026-10-22。AIS 的 PT 环境 7 个 VC Job 接口均返回 404，而 `ait list -n 1` 正常返回任务。

`rayctl -e pt ate get <任务名>` 现在直接显示：

```text
PT 环境没有 ATE 服务，请用 ait
```

只在当前环境为 PT、全部 profile 的 VC 清单查询完成、至少探测一个 VC，且所有 Job 接口都返回 HTTP 404 时使用该提示。任何成功响应（包括空列表）、权限错误、其他 HTTP 错误、超时、取消或不完整的清单查询，都不会被这条提示掩盖。D 环境的 404 保留原有错误。

HTTP 状态现在作为结构化错误供 ATE 判断；其他调用者的错误文字保持原样，响应正文里出现“404”不会触发误判。确认未提供 ATE 后跳过 HC 回退，不再输出重复 URL。查询仍退出 1；JSON 的 `errors` 包含同一条提示。
